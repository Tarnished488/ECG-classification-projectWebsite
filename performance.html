What is SHAP?

SHAP (SHapley Additive exPlanations) is a game-theoretic approach to explain machine learning model predictions. Each feature is assigned an importance value (SHAP value) representing its contribution to pushing the prediction away from the base value. Positive SHAP values push toward "abnormal" classification; negative values push toward "normal."

Chart Types Explained

  • Summary Plot — Each dot is one prediction. Color = feature value (red=high, blue=low). X-axis = SHAP impact. Top features = most important.
  • Bar Plot — Mean absolute SHAP value per feature. Taller bar = more important globally.
  • Dependence Plot — SHAP value vs. actual feature value for a single feature. Reveals the direction and shape of feature influence.
  • Force Plot — Single-instance explanation. Red arrows push toward abnormal, blue toward normal. Shows exactly which features drove one specific prediction.

MULTI-MODEL COMPARISON (Test Set — DS2)

Performance comparison of all 6 classifiers on the held-out DS2 test set (18 patients, 49,691 beats). All models share identical preprocessing (Butterworth bandpass + double median filter), feature set (88 MATLAB-style features → Top20 via LR coefficients), and SMOTE 0.4 oversampling. Each model uses its own optimal decision threshold found via validation set F1 maximization.

Key Insight: LogisticRegression achieves the best generalization (smallest Train-Test Gap = 0.0325). Tree-based models (RF, XGBoost, GBDT) severely overfit on DS1, showing large gaps of 0.28–0.40. SVM has the worst overall performance despite moderate recall. The simpler linear model generalizes best to unseen patients.

Derived Metrics

True Negatives (TN): 42,778 — Normal correctly identified as normal

False Positives (FP): 1,255 — Normal incorrectly flagged as abnormal

False Negatives (FN): 772 — Abnormal missed (most critical errors)

True Positives (TP): 4,886 — Abnormal correctly detected

Accuracy: (42,778 + 4,886) / 49,691 = 95.92%

Precision: 4,886 / (4,886 + 1,255) = 79.56%

Recall (Sensitivity): 4,886 / (4,886 + 772) = 86.36%

Specificity: 42,778 / (42,778 + 1,255) = 97.15%

False Positive Rate: 1,255 / (42,778 + 1,255) = 2.85%

False Negative Rate: 772 / (4,886 + 772) = 13.64%
