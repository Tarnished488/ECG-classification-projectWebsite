01 PROJECT PURPOSE

This project develops an interpretable machine learning system for automatic detection of abnormal heartbeats from ECG signals using the MIT-BIH Arrhythmia Database.

By combining handcrafted wavelet, HOS, distance, amplitude, and RR-interval features with SHAP explainability, the system achieves high accuracy while providing transparent and clinically meaningful interpretations.

Key Functions

def bandpass_filter(signal, fs, lowcut=0.5, highcut=40.0, order=4):
    """Apply Butterworth bandpass filter to ECG signal."""
    nyquist = 0.5 * fs
    low, high = lowcut / nyquist, highcut / nyquist
    b, a = sp_signal.butter(order, [low, high], btype='band')
    filtered = np.zeros_like(signal)
    for i in range(signal.shape[1]):
        filtered[:, i] = sp_signal.filtfilt(b, a, signal[:, i])
    return filtered

def remove_baseline_wander(signal, fs=360):
    """Remove baseline wander using double median filter method.
    Step 1: 71-sample median filter removes QRS complexes
    Step 2: 215-sample median filter removes P and T waves
    Baseline = second filtered signal; Corrected = original - baseline
    """
    filtered_qrs = median_filter(channel, size=71, mode='nearest')
    baseline = median_filter(filtered_qrs, size=215, mode='nearest')
    return signal - baseline

Multi-Stage Feature Selection

Technologies Used

  • sklearn.feature_selection.VarianceThreshold — Remove constant/low-variance features (threshold=0.01)
  • Pearson correlation filter — Remove highly correlated redundant features (threshold=0.95)
  • sklearn.linear_model.LassoCV — L1-regularized feature selection for linear classifiers (Logistic Regression, SVM)
  • sklearn.feature_selection.SelectFromModel(RandomForest) — Tree-based importance selection for non-linear classifiers (RF, XGBoost, LightGBM)
  • sklearn.feature_selection.RFE — Recursive feature elimination as alternative method

Key Functions

def run_feature_selection(features, labels, method='auto',
    classifier_type='linear', variance_threshold=0.01,
    correlation_threshold=0.95, cv=5):
    """3-stage pipeline:
    1. VarianceThreshold → remove near-constant features
    2. Correlation filter → drop redundant features (r > 0.95)
    3. Final selection → LassoCV (linear) or
       SelectFromModel(RF) / RFE (non-linear)
    Returns: selected matrix, indices, pipeline_info dict
    """

def select_with_lassocv(X, y, cv=5):
    """Select features where LassoCV coef_ != 0.
    Input X should be pre-standardized."""
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)
    lasso = LassoCV(cv=cv, max_iter=10000).fit(X_scaled, y)
    selected_indices = np.where(lasso.coef_ != 0)[0].tolist()
    return X[:, selected_indices], selected_indices

Technologies Used

  • shap.summary_plot — Global feature importance dot-plot (SHAP value distribution per feature)
  • shap.dependence_plot — Single-feature SHAP vs feature value (interaction detection)
  • shap.force_plot — Single-instance local explanation (base value + feature push/pull)

Key Functions

def select_explainer(model, X, model_type='auto'):
    """Auto-detect model type and return the right SHAP explainer."""
    model_class = type(model).__name__.lower()
    if any(t in model_class for t in
           ['forest','tree','xgboost','lgbm','gradientboosting']):
        return shap.TreeExplainer(model)
    elif any(l in model_class for l in ['logistic','linear','svc']):
        background = shap.sample(X, 100)
        return shap.LinearExplainer(model, background)
    else:
        background = shap.sample(X, 100)
        return shap.KernelExplainer(model.predict, background)

def analyze_feature_importance(shap_values, feature_names):
    """Rank features by mean(|SHAP|) across all samples."""
    shap_mean = np.mean(np.abs(shap_values), axis=0)
    return pd.DataFrame({
        'feature': feature_names,
        'mean_abs_shap': shap_mean
    }).sort_values('mean_abs_shap', ascending=False)

03 EXPERIMENTAL PROCEDURE

  1. Data Loading — Read 48 MIT-BIH records from CSV, parse MLII + V1 signals and beat annotations
  2. Signal Preprocessing — Double median filter baseline removal + 0.5–40 Hz Butterworth bandpass filter
  3. Beat Segmentation — Extract 181-sample windows around R-peaks (90 left, 90 right), filter to valid AAMI beat types
  4. Feature Extraction — Wavelet (db1, L3 approx coeffs) + HOS (5-interval skew/kurtosis) + Distance (P-Q-S-T fiducial) + Amplitude + RR-interval (8 temporal features)
  5. Feature Selection — VarianceThreshold → Correlation filter → LassoCV (for linear classifier), reducing to top informative features
  6. Standardization + DS1/DS2 Split — StandardScaler + inter-patient train/test split (18 DS1 records / 18 DS2 records)
  7. Class Imbalance Handling — SMOTE (k=5, ratio=0.8) and BorderlineSMOTE on training set only
  8. Model Training — Logistic Regression (C=0.5, L2) as primary model; RF, XGBoost, LightGBM, SVM as baselines
  9. Evaluation — Accuracy, precision, recall, F1, AUC on DS2 test set (strictly unseen patients)
  10. SHAP Analysis — TreeExplainer/LinearExplainer → summary plot, bar plot, dependence plots, force plots for global + local interpretability
